# [メール文作成 AI エージェント] 要件定義書

## 📋 概要

メールの返信、送信を対話形式で考えてくれる AI エージェント。考え終わったメール文はまとめて出力してくれる。

## 🎯 要求

- ユーザーはメール返信を一度もしたことがなく、メール返信文の書き方が全く分からない
- 最初は新規送信メールか返信メールかを選択する
- 返信、送信は目上の人にすることに限定する。そのため、丁寧な言葉での返信が必要
- 本文では、できるだけ最小限の入力にしたい。メール返信の要件を手短に聞いて、情報収集・質問・文章作成の 3 段階でエージェントが対話的にメール文を作成する
- 最後まで言ったら、それをまとめる作業をする。ここでは文章作成エージェントが個人の RAG などを閲覧して最後メールの返信としてまとめる

## 📝 機能仕様

### 画面/コンポーネント構成

ターミナルで会話する。そのため、画面等は必要なし。ターミナルに出てくる文字を少しおしゃれにしてくれると嬉しい。

### 振る舞い

#### 初期設定

- 最初に新規送信メールか返信メールかを選択する
- 個人情報（所属、名前、住所、メールアドレス、電話番号）は RAG で管理し、初回はダミー情報を設定
- 個人情報の更新は直接ファイル編集で行う

#### 新規送信メールの場合

1. 送信の目的を選択（例：「お礼」「依頼」「報告」「質問」など）
2. メールの件名を入力
3. 送信先の所属と名前を入力
4. 情報収集エージェントが必要な情報を収集
5. 質問エージェントが内容に応じて追加質問
6. 文章作成エージェントが RAG や個人情報を参照しメール文を作成

#### 返信メールの場合

1. 差出人の所属と名前を入力
2. 元のメールの本文をコピペで貼り付け
3. 情報収集エージェントが必要な情報を収集
4. 質問エージェントが内容に応じて追加質問
5. 文章作成エージェントが RAG や個人情報を参照しメール文を作成

#### 最終出力

- 最終的にまとめられたメール文は以下の形式で表示：

```
┌─────────────────────────────────────┐
│ 件名: [件名]                        │
│ 送信先: [所属] [名前]               │
│                                     │
│ [本文]                             │
└─────────────────────────────────────┘
```

### 制約条件

- 実装は python で、langgraph を使う
- LLM を利用するにあたって OPENAI_API_KEY は.env の中にある
- 返信、送信は目上の人に限定
- 出力形式はプレーンテキスト

## 📊 データ要件

### 個人情報管理（RAG）

- 会社名
- 部署名
- 名前
- 住所
- メールアドレス
- 電話番号
- 初回はダミー情報を設定（例：「株式会社サンプル 営業部 田中太郎」）

### メール文構成

- 挨拶
- 本題
- 締めの文

## 🔄 インタラクション

### エラー処理

- ユーザーが不適切な入力をした場合はエラーメッセージを表示して再度入力させる
- エラーメッセージ例：「入力が正しくありません。再度入力してください。」
- AI が適切な選択肢を生成できない場合は再試行なしで一番適切だと思うものを出力
